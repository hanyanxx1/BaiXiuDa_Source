# 📑 PSCC 系统外呼数据专项清洗 SOP (标准作业程序)

## 一、 核心目的与前置准备
**目的**：定期清理 `customer_info` 库中大量冗余重复的号码数据，降低 MySQL 内存与磁盘 IO 压力，同时对剩余唯一号码进行洗牌与格式重组，防止外呼系统对同一客户高频骚扰，提高外呼接通率与转化率。
**周期**：建议每 1~3 个月，或总数据量突破 5000 万时执行一次。
**前置准备**：
1. **服务器权限**：拥有 42 集群主控服务器的 Root SSH 登录权限。
2. **本地环境**：本地 Windows 电脑已安装 Python，并且在终端执行过 `pip install pywin32`（用于静默调用 Excel 刷格式）。
3. **清洗脚本**：本地已准备好最终版的 `clean_data.py` 脚本文件。

---

## 二、 Step 1：服务器端全量原始数据导出（全程约 1-3 分钟）
*此步骤利用纯底层 SQL 将所需字段导出为 TSV 格式，完全避开内存溢出风险。*

1. 使用 SSH 工具（如 FinalShell、Xshell）登录 **42集群主控服务器**。
2. 复制并直接在命令行执行以下导出命令：
   ```bash
   mysql -uroot -p'userisahsj' -D cc -N -q -e "SELECT telephone, name, fields FROM customer_info;" > /var/lib/mysql-files/raw_full_data.tsv
   ```
3. **注意**：敲下回车后，屏幕光标会停止闪烁或卡住，此时底层正在疯狂写盘。**切勿按 `Ctrl+C` 强行中断**。等光标恢复正常，即代表导出完成。

---

## 三、 Step 2：将数据下载至本地处理
*此步骤将巨大的运算压力转移至本地，彻底保护线上生产环境。*

1. 在 SSH 工具的文件管理器中，进入 `/var/lib/mysql-files/` 目录。
2. 找到刚才生成的 `raw_full_data.tsv` 文件。
3. 右键点击下载，将其保存到本地电脑的一个充裕的磁盘中（例如 `D:\PSCC清洗数据\`）。
4. （可选）为保持服务器整洁，下载确认无误后，可在服务器端执行 `rm -f /var/lib/mysql-files/raw_full_data.tsv` 删除该临时大文件。

---

## 四、 Step 3：本地执行自动化清洗与打格式（全程约 2-5 分钟）
*此步骤将完成：千万级去重 -> 乱序洗牌 -> 扒取 JSON 匹配表头 -> 按 5 万行切分文件 -> 复杂命名归档 -> 自动调用 Excel 静默刷新并保存。*

1. 打开本地电脑的 **cmd** 或 **PowerShell** 黑窗口。
2. 输入 `python D:\你的脚本路径\clean_data.py` 并回车执行。
3. 根据屏幕交互提示，依次输入或确认 4 个参数：
   * **输入文件路径**：直接把下载好的 `raw_full_data.tsv` 拖拽到黑窗口中回车。
   * **输出保存目录**：输入你想要存放成品文件的空文件夹路径（如 `D:\PSCC清洗数据\ready_to_import`）。
   * **切割行数**：直接回车（默认 50000 行）。
   * **日期后缀**：直接回车（默认当天日期，或手动输入如 `04.15`）。
4. 核对执行清单无误后，输入 `q` 确认开始。
5. 等待脚本跑完最后一步（Excel 引擎后台静默刷新）。当出现 **“✅ [大功告成]”** 且打印出最终的对账数字时，数据已完美备好。

---

## 五、 Step 4：PSCC 业务后台平滑置换（防卡死核心操作）
*此步骤是将洗好的“干净血液”重新注入业务系统，必须极度小心。*

**⚠️ 致命警告：绝不可在前端列表“一键全选”并删除所有任务！**
*(一次性发送几千万行的 DELETE 指令会导致 MySQL 表级死锁，线上所有外呼会瞬间全盘崩溃。)*

1. **蚂蚁搬家式删旧任务**：
   * 登录 PSCC 后台的外呼任务列表。
   * **每次仅勾选 10 ~ 20 个旧任务**，点击删除。
   * 删完一批，停顿 3-5 秒，让 MySQL 底层消化完事务日志，然后再删下一批，直到旧任务被完全清空。
2. **导入全新干净任务**：
   * 打开本地的输出目录（如 `ready_to_import`）。
   * 你会看到按规则生成的 `1-99`、`2-99` 等归档文件夹。
   * 依次进入文件夹，按顺序（如 `1-HB1-0...`, `2-HB1-0...`，随后是 `A1-HB1...` 等）将这些已经过 Excel 底层格式化的 `.csv` 文件，直接拖拽导入 PSCC 后台建立新任务。
